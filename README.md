# Payment Processing Platform

A simple payment processing API built with C# and ASP.NET Core Web API.

The project is part of my journey to deepen my knowledge of .NET backend development and practise building real-world APIs.

### Technologies
- C#
- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- SQLite
- xUnit

### Features
- Customer management
- Payment creation and retrieval
- Repayment processing
- Payment status management
- Transaction history
- Idempotency handling

### Run the project

```bash
dotnet restore
dotnet run --project Paymentprocess.Api
```

### Run tests

```bash
dotnet test
```
